Chapters

    Words you will hear

    Repository (repo)
    A project folder tracked by Git, so every change is saved and can be undone.
    API
    The server program that receives requests and decides what is allowed.
    Tenant
    One customer company sharing the app. North and South here, both fake.
    Status code
    The server's short answer: 200 OK, 401 who are you, 403 not allowed, 404 not found, 409 conflict.
    Idempotency key
    A receipt number on a request, so a retry never does the same thing twice.
    Transaction
    A group of database changes that all happen together, or not at all.
    Mock
    A fake stand-in used in tests. Dangerous when it replaces the very check you are testing.
    Plan mode
    A Claude Code mode where it can read and think but cannot change files.
    CLAUDE.md
    A short file of project rules that Claude reads on every request.
    Hook
    A small script Claude Code runs automatically before or after an action. It can block it.
    Deny rule
    A line in .claude/settings.json that forbids an action. The model cannot argue with it.
    Subagent
    A helper Claude with its own limited tool list, such as a read-only reviewer.
    Mutation check
    Break the code on purpose. If the tests still pass, they were not testing anything.
